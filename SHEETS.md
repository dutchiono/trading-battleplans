| I | Edge Size | Text | Small/Medium/Large/Huge | `=IF(ABS(H2)<5%,"Small",IF(ABS(H2)<10%,"Medium",IF(ABS(H2)<20%,"Large","Huge")))` |
| J | Liquidity | Currency | Total liquidity available | Polymarket API |
| K | Volume 24h | Currency | 24h trading volume | Polymarket API |
| L | Resolution Date | Date | When market closes | Polymarket API |
| M | Days to Close | Number | Time remaining | `=L2-TODAY()` |
| N | Risk Score | Number (1-10) | Overall risk assessment | Calculated composite |

| R | Entry Price | Number | Actual entry price if traded | Manual entry |

| T | P&L | Currency | Profit/loss if traded | `=(S2-R2)*shares` |
| U | Notes | Text | Additional context | Manual notes |

**Conditional Formatting:**
- **Edge (Column H):**
  - Green: >+10% (strong positive edge)
  - Light Green: +5% to +10%
  - Yellow: -5% to +5% (no clear edge)
  - Light Red: -5% to -10%
  - Red: <-10% (strong negative edge)

- **Risk Score (Column N):**
  - Green: 1-3 (low risk)
  - Yellow: 4-6 (medium risk)
  - Orange: 7-8 (high risk)
  - Red: 9-10 (extreme risk)

- **Status (Column Q):**
  - Blue: WATCHING
  - Green: ENTERED
  - Gray: CLOSED
  - Red: SKIPPED

**Data Validation:**
- Column Q (Status): Dropdown list = {WATCHING, ENTERED, CLOSED, SKIPPED}

## Automation Flow

### How Data Gets to Sheets

1. **Polymarket Edge Detector Script Runs**
   - Fetches markets from Polymarket Gamma API
   - Scrapes external data (polls, news, models)
   - Calculates edge for each market
   - Filters for minimum edge threshold (e.g., >5%)

2. **Script Authenticates with Google Sheets**
   - Uses Google Sheets API
   - OAuth credentials stored in Nebula
   - Scopes: `spreadsheets` (read/write)

3. **Data Validation**
   - Check for duplicate markets (by ID)
   - Validate data types and ranges
   - Calculate derived fields (edge %, risk score)

4. **Sheet Update**
   - Append new rows to "Edge Candidates" tab
   - Update existing rows if market already listed
   - Sort by Edge % (descending)
   - Apply conditional formatting

5. **Notification**
   - If edge >15%, send alert (Telegram/email)
   - Summary posted to Nebula chat

### Manual Workflow

1. **Morning Review:**
   - Open Google Sheets
   - Review new Edge Candidates (sorted by Edge %)
   - Check Research Probability sources
   - Assess Risk Score

2. **Decision Making:**
   - High conviction (>10% edge, risk <5): ENTER
   - Medium edge (5-10%): WATCHING
   - Low edge or high risk: SKIP

3. **Trade Entry:**
   - Update Status → ENTERED
   - Record Entry Price
   - Set alerts for resolution date

4. **Trade Exit:**
   - Update Exit Price when market resolves
   - Status → CLOSED
   - Calculate P&L
   - Add notes on what worked/didn't work

5. **Weekly Review:**
   - Analyze closed positions
   - Calculate win rate and edge accuracy
   - Refine research probability models

## Formulas Reference

### Risk Score Calculation
Composite score based on multiple factors:

```
=IF(J2<$10K, 3, 0) +                    // Low liquidity = +3 risk
 IF(K2<$1K, 2, 0) +                     // Low volume = +2 risk  
 IF(M2<7, 2, 0) +                       // <7 days to close = +2 risk
 IF(ABS(H2)>20%, -2, 0) +               // Huge edge = -2 risk (good)
 IF(G2="", 5, 0)                        // No research = +5 risk

Result: 1-10 scale (1=safest, 10=riskiest)
```

### Recommendation Logic
```
=IF(AND(H2>10%, N2<5), "BUY YES - High Conviction",
 IF(AND(H2<-10%, N2<5), "BUY NO - High Conviction",
 IF(AND(ABS(H2)>5%, N2<7), "CONSIDER",
 "SKIP")))
```

### Position Size Calculation
Kelly Criterion modified for risk:
```
=MIN(
  (G2*ABS(H2)-D2)/(ABS(H2)),            // Kelly formula
  IF(N2<4, 10%, IF(N2<7, 5%, 2%))       // Risk-based cap
)

Low risk (1-3): Max 10% of capital
Medium risk (4-6): Max 5%
High risk (7-10): Max 2%
```

## Google Sheets API Setup

### Authentication (One-Time Setup)

1. **Enable Google Sheets API**
   - Go to [Google Cloud Console](https://console.cloud.google.com/)
   - Create new project: "Nebula Trading System"
   - Enable "Google Sheets API"

2. **Create OAuth Credentials**
   - APIs & Services → Credentials
   - Create OAuth 2.0 Client ID
   - Application type: Desktop app
   - Download JSON credentials

3. **Connect to Nebula**
   - Upload credentials to Nebula (secure storage)
   - Run initial authentication flow
   - Nebula stores refresh token for auto-renewal

### API Scopes Required
```
https://www.googleapis.com/auth/spreadsheets
https://www.googleapis.com/auth/drive.file
```

### Rate Limits
- **Read requests:** 100 per 100 seconds per user
- **Write requests:** 100 per 100 seconds per user
- **Batch operations:** Recommended for bulk updates

### Code Example (Python)
```python
from googleapiclient.discovery import build
from google.oauth2.credentials import Credentials

# Authenticate
creds = Credentials.from_authorized_user_file('token.json', SCOPES)
service = build('sheets', 'v4', credentials=creds)

# Get sheet
SPREADSHEET_ID = 'your_sheet_id_here'
RANGE_NAME = 'Edge Candidates!A2:U'

# Read data
result = service.spreadsheets().values().get(
    spreadsheetId=SPREADSHEET_ID,
    range=RANGE_NAME
).execute()
values = result.get('values', [])

# Write data
new_row = [
    '2026-02-11',                          # Date
    'Will BTC hit $50K by March?',         # Market
    'Crypto',                              # Category
    0.65,                                  # Yes price
    0.35,                                  # No price
    '65%',                                 # Implied prob
    '78%',                                 # Research prob
    '+13%',                                # Edge
    'Large',                               # Edge size
    '$125,000',                            # Liquidity
    '$8,400',                              # Volume
    '2026-03-01',                          # Resolution
    18,                                    # Days to close
    3,                                     # Risk score
    'BUY YES - High Conviction',           # Recommendation
    '8%',                                  # Position size
    'WATCHING',                            # Status
    '',                                    # Entry price
    '',                                    # Exit price
    '',                                    # P&L
    'Strong technical support at $48K'     # Notes
]

body = {'values': [new_row]}
service.spreadsheets().values().append(
    spreadsheetId=SPREADSHEET_ID,
    range='Edge Candidates!A2',
    valueInputOption='USER_ENTERED',
    body=body
).execute()
```

## Troubleshooting

### Common Issues

**1. Script can't connect to Sheets**
- **Cause:** OAuth token expired
- **Fix:** Re-authenticate via Nebula
  ```python
  # Trigger re-auth in Nebula
  run_action(action_key='google_sheets-auth-refresh')
  ```

**2. Data not updating**
- **Cause:** API rate limit hit
- **Fix:** Add exponential backoff
  ```python
  import time
  for attempt in range(3):
      try:
          # API call here
          break
      except HttpError as e:
          if e.resp.status == 429:
              time.sleep(2 ** attempt)
  ```

**3. Formulas breaking**
- **Cause:** Script overwrites formula cells
- **Fix:** Only update data columns (A-M), not formula columns (N-U)
  ```python
  # Write to specific range
  range_name = 'Edge Candidates!A2:M2'  # Exclude formula columns
  ```

**4. Duplicate entries**
- **Cause:** No duplicate check before insert
- **Fix:** Query existing market IDs first
  ```python
  existing = service.spreadsheets().values().get(...).execute()
  market_ids = [row[25] for row in existing['values']]  # Assuming ID in column Z
  if new_market_id not in market_ids:
      # Insert new row
  ```

## Best Practices

### Data Hygiene
1. **Archive old data monthly** - Move closed positions to separate "Archive" tab
2. **Validate on insert** - Check data types before writing
3. **Use named ranges** - Easier to reference in code
4. **Version control** - Keep backup copies of sheet structure

### Performance
1. **Batch updates** - Update multiple rows in single API call
2. **Cache reads** - Don't query same data repeatedly
3. **Use filters** - Pre-filter in script, not in sheet
4. **Limit formulas** - Heavy formulas slow down large sheets

### Security
1. **Read-only sharing** - Share view-only links publicly
2. **API credentials** - Never commit to Git
3. **Restricted scopes** - Only request necessary permissions
4. **Audit logs** - Review who accessed/modified sheet
